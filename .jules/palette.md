## 2025-05-15 - Improving Sidebar Action Discoverability
**Learning:** Visual keyboard shortcut hints (e.g., `[R]`, `[/]`, `[Esc]`) significantly improve discoverability for power-user features in a terminal/brutalist aesthetic without cluttering the UI. Adding descriptive `aria-label` attributes to icon-only or atmospheric buttons ensures that accessibility is not sacrificed for style.
**Action:** Always pair global keyboard shortcuts with visible hints using the `text-[10px] text-white/20 font-mono` style and provide explicit ARIA labels for atmospheric actions like "Waste Time".
