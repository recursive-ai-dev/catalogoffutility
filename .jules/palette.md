## 2025-05-25 - Sidebar Shortcut Hints and Keyboard Accessibility
**Learning:** Keyboard shortcuts in complex apps like the Archive need both visual discoverability (hints like [R]) and technical isolation (isInputFocused checks) to ensure they enhance rather than hinder the user experience.
**Action:** When adding keyboard shortcuts, always pair them with visible hints in the UI and a robust focus check to prevent collisions with text entry fields.
